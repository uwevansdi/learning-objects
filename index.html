Learning objects

Interactive pieces built for Evans courses. Open one to try it, or copy its embed code into a Canvas page.

    Adding one to Canvas

    1. In a Canvas Page, click Edit.
    2. Click the </> icon (bottom right of the editor) to open the HTML editor.
    3. Paste the embed code where the object should appear, then Save.
    4. Check it in Student View.

    These pages collect no student data. Questions or fixes: Evans Digital.
